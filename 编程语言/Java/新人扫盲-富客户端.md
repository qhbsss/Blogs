## 富客户端

- 富客户端是指通过缓存前置的思想，将缓存逻辑放到客户端（一般指二方包）中，降低向服务端发起的HSF调用次数，进而降低服务端QPS的解决方案。
- 应用场景：读多写少的高QPS应用，如UIC，IC等。

注: 本文中所提及的服务端和客户端定义如下  
服务端：服务的提供方，一般指提供二方包的应用；  
客户端：服务的调用方，一般指引用二方包的应用，包括普通客户端和富客户端。

## 富客户端原理

## 普通客户端实现原理：

hsf服务，为解决高QPS服务端机器性能问题，通常在服务端增加缓存机制。一次服务调用如图，1. 客户端调用HSF服务；2. 服务端发起远程请求tair缓存，命中返回调用方；3. 未命中读取底层存储，写tair并返回调用方。  

![[03833d0c-3a39-447f-9122-ee861690b799.jpeg|普通客户端查询过程.jpg]]

普通客户端查询过程.jpg

## 富客户端实现原理：

为进一步降低服务器机器压力，将缓存逻辑前置在调用方中，一次服务调用如图：1. 调用方发起远程请求tair，命中返回；2. 未命中发起hsf调用。

## 比较

缓存命中时，二者比较：

|  | hsf调用 | tair调用 |
| --- | --- | --- |
| 普通客户端 | 需要 | 需要 |
| 富客户端 | 不需要 | 需要 |

普通客户端采用中心化的方式，所有的请求都需要服务端进行，故当命中缓存时，请求仍会打到服务端机器上。而富客户端通过缓存前置，避免了命中缓存时的hsf调用，进而降低了服务端机器的压力。故：高qps场景下，富客户端表现更优。

## 富客户端实现-以招商富客户端为例

富客户端的具体实现，有各种版本但期原理基本相同，本文以招商富客户端实现为例，进行阐述。

## 使用技术：

使用spring+JDK动态代理+注解的方式实现：  
  
spring负责：tairManager和HsfConsumer的创建，以及对应bean的生命周期管理。  
  
JDK动态代理负责：控制先查缓存，缓存未命中再调用HSF的逻辑  
  
注解（包括RichClientCached和CacheKey）负责：控制那些接口需要走缓存，以及缓存相关的配置如nameSpace,key,expireSecond等。

```java
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
@Documented
public @interface RichClientCached {
    /**
     * 是否需要被缓存,默认为true
     */
    boolean clientCache() default true;

    /**
     * 服务端是否需要被缓存,默认为true
     */
    boolean severCache() default true;

    /**
     * tair的缓存namespace
     */
    int namespace();

    /**
     * 缓存前缀
     */
    String cachePrefix();

    /**
     * tair的失效时间
     */
    int expireSecond();

    /**
     * 从缓存中读取到NullObjec对象是否直接返回，不穿透到后端服务
     */
    boolean fastReturnNullObject() default false;
}
```

import com.alibaba.honolulu.common.NullObject;
import com.alibaba.honolulu.common.bean.BeanResourceFactory;

import com.alibaba.ju.common.service.ResultDO;

import java.lang.reflect.InvocationHandler;
import java.lang.reflect.InvocationTargetException;
import java.lang.reflect.Method;
import java.lang.reflect.Proxy;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

public class CacheProxy<T> implements InvocationHandler {
    private final Logger logger = LoggerFactory.getLogger(this.getClass());
    private T target;
    private TairManager tairManager;

    public CacheProxy(TairManager tairManager) {
        if (tairManager == null) {
            this.logger.error("invalid tair manager");
            throw new RuntimeException("invalid tair manager");
        } else {
            this.tairManager = tairManager;
        }
    }

    public T bind(T target) {
        this.target = target;
        return Proxy.newProxyInstance(target.getClass().getClassLoader(), target.getClass().getInterfaces(), this);
    }
      // 1. 先从缓存查，命中直接返回结果
    // 2. 为命中，调用HSF
    public Object invoke(Object proxy, Method method, Object[] args) throws Throwable {
        if (this.target == null) {
            this.logger.error("CacheProxy target not bound, method=" + method.getName());
            throw new RuntimeException("CacheProxy target not bound");
        } else {
            // 利用RichClientCached和CacheKey构造cacher
            TairCacher cacher = TairCacher.build(this.logger, this.tairManager, method, args, BeanResourceFactory.appInfo == null ? "" : BeanResourceFactory.appInfo.getAppName());
            Object rs;
            // 先从缓存中查，命中则直接返回结果
            if (cacher.needClientReadCache && !StressTestingUtil.isTestFlow()) {
                rs = cacher.getFromCache();
                if (rs != null) {
                    if (rs instanceof NullObject) {
                        return (new ResultDO()).setValue((Object)null);
                    }

                    return (new ResultDO()).setValue(rs);
                }
            }

            try {
                // 缓存未命中，调用HSF
                rs = method.invoke(this.target, args);
            } catch (InvocationTargetException var7) {
                throw var7.getCause();
            }

            if (cacher.needClientWriteCache && !StressTestingUtil.isTestFlow()) {
                cacher.putIntoCache((ResultDO)rs);
            }

            return rs;
        }
    }
}

public class TairCacher {
    private static final Logger cacheLogger = LoggerFactory.getLogger(TairCacher.class);
    private static DiamondHelper<Properties> cacheProperty = new DiamondHelper<Properties>("tmc_business_cache_property", "tmc-business") {
        protected Properties buildValue(String s) {
            Properties properties = new Properties();

            try {
                properties.load(new StringReader(s));
            } catch (Exception var4) {
                TairCacher.cacheLogger.error("parse cacheProperty exception, dataId=tmc_business_cache_property,group=tmc-business, config={}", s, var4);
            }

            return properties;
        }
    };
    Logger logger;
    TairManager tairManager;
    Method method;
    public boolean needClientReadCache = false;
    public boolean needClientWriteCache = false;
    public boolean needServerCache = false;
    public boolean fastReturnNullObject = false;
    int namespace = 0;
    String cachePrefix = "";
    String cacheKey = "";
    int expireSecond = 0;

    // 判断该请求应用是否在忽略缓存的应用配置中，如在则缓存不生效，每次都需要走HSF调用
    public static boolean ignoreCache(String appName) {
        if (!Strings.isNullOrEmpty(appName) && cacheProperty != null && cacheProperty.getValue() != null) {
            String ignoredCacheApps = ((Properties)cacheProperty.getValue()).getProperty("ignoredCacheApps");
            return Strings.isNullOrEmpty(ignoredCacheApps) ? false : Splitter.on(",").splitToList(ignoredCacheApps).contains(appName);
        } else {
            return false;
        }
    }

    private TairCacher() {
    }
    // 通过解析RichClientCached和CacheKey注解，构造TairCacher
    public static TairCacher build(Logger logger, TairManager tairManager, Method method, Object[] args, String appName) {
        TairCacher cacher = new TairCacher();
        RichClientCached cachedAn = (RichClientCached)AnnotationUtils.getAnnotationByClz(method.getAnnotations(), RichClientCached.class);
        if (cachedAn != null) {
            cacher.needClientReadCache = cachedAn.clientCache();
            cacher.needServerCache = cachedAn.severCache();
            cacher.namespace = cachedAn.namespace();
            cacher.cachePrefix = cachedAn.cachePrefix();
            cacher.expireSecond = cachedAn.expireSecond();
            cacher.cacheKey = buildCacheKey(method.getParameterAnnotations(), args);
            cacher.fastReturnNullObject = cachedAn.fastReturnNullObject();
        }

        if (ignoreCache(appName)) {
            cacher.needClientReadCache = false;
            cacher.needServerCache = false;
        }

        cacher.tairManager = tairManager;
        cacher.logger = logger;
        cacher.method = method;
        return cacher;
    }

    public static String buildCacheKey(Annotation[][] allParaAnnotations, Object[] args) {
        List<Object> obKeys = AnnotationUtils.getKeys(args, allParaAnnotations, CacheKey.class);
        return obKeys != null && obKeys.size() != 0 ? Joiner.on("_").join(Lists.transform(obKeys, new Function<Object, String>() {
            public String apply(Object input) {
                return input != null && input instanceof CacheKeyable ? ((CacheKeyable)input).buildUniqKey() : String.valueOf(input);
            }
        })) : "";
    }

    public Object getFromCache() {
        if (StressTestingUtil.isTestFlow()) {
            this.logger.warn("Tair key=" + TairNamespaceHolder.getNamespace(this.namespace) + ", test flag");
            return null;
        } else {
            Result<DataEntry> result = this.tairManager.get(TairNamespaceHolder.getNamespace(this.namespace), this.getFullCacheKey());
            if (result != null && result.isSuccess()) {
                DataEntry dataEntry = (DataEntry)result.getValue();
                if (dataEntry != null) {
                    if (dataEntry.getValue() instanceof NullObject && !this.fastReturnNullObject) {
                        return null;
                    }

                    return dataEntry.getValue();
                }
            }

            return null;
        }
    }
    // 添加到缓存中
    public void putIntoCache(ResultDO resultDO) {
        if (resultDO.isSuccess()) {
            Serializable tobeCachedValue = new NullObject();
            if (resultDO.getValue() != null) {
                if (resultDO.getValue() instanceof Serializable) {
                    tobeCachedValue = (Serializable)resultDO.getValue();
                } else {
                    this.logger.error("{} value not Serializable, cannot be cached, method={}, namespace={}, cacheKey={}", new Object[]{this.getClass(), this.method.getName(), TairNamespaceHolder.getNamespace(this.namespace), this.getFullCacheKey()});
                }
            }

            if (!ShadowTairUtils.isTestFlowPutTair("honolulu")) {
                return;
            }

            ResultCode putRs = this.tairManager.put(TairNamespaceHolder.getNamespace(this.namespace), this.getFullCacheKey(), (Serializable)tobeCachedValue, 0, this.expireSecond);
            if (putRs.isSuccess()) {
                this.logger.info("put into cache success, namespace={},key={},message={}", new Object[]{TairNamespaceHolder.getNamespace(this.namespace), this.getFullCacheKey(), putRs.getMessage()});
            } else {
                this.logger.error("put into cache failed, namespace={},key={},message={}", new Object[]{TairNamespaceHolder.getNamespace(this.namespace), this.getFullCacheKey(), putRs.getMessage()});
            }
        }

    }
}
